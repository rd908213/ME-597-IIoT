df['time'] = pd.to_datetime(df["Timestamp"])

t1 = time - time[0]
temperatureC = df['Temperature (°C)']
temperatureF = df['Temperature (°F)']

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5)) # Creates a new figure with 2 subplots side by side
fig.suptitle('Temperature graphs in Celsius and Fahrenheit', fontsize=20) # overall title for the figure

ax1.set_title('Temperature graph (°C)',fontsize= 12) # title of plot
ax1.set_xlabel('seconds',fontsize = 10) #xlabel
ax1.set_ylabel('Degree of Celsius', fontsize = 10) #ylabel

ax2.set_title('Temperature graph (°F)',fontsize= 12) # title of plot
ax2.set_xlabel('seconds',fontsize = 10) #xlabel
ax2.set_ylabel('Degree of Fahrenheit', fontsize = 10) #ylabel

ax1.plot(t1,temperatureC,'-o') #plotting the data with marker '-o'
ax2.plot(t1,temperatureF,'-o') #plotting the data with marker '-o'

Lab1 Summary and Deliverables¶

Answer the following questions for your achievements

Q1. Please summarize Lab1.¶

In Lab 1, we learned how to set up a raspberry pi to take input from a 1-wire sensor device using the GPIO pins. We also learned how the bus connector works and how to view the pinout to verify that we are using the correct pins to connect our sensors. Finally, we used how to communicate with the sensors using python and took temperature measurements. We also learned how to graph these temperature measurements using matplotlib pyplot.

Q2. What skills did you have to develop to accomplish this project?¶

I needed to develop better command line skills through bash, troubleshooting, and more python skills.

Q3. What aspects of this project were the most beneficial for your learning?¶

The most beneficial aspects of this project were learning more about the configuration of the raspberry pi and where settings are stored. Also, it was beneficial to learn how to communicate with external devices over the 1-wire GPIO pins.

Q4. What challenges did you encounter in completing the project?¶

Because of the winter weather and dry winter air inside my house, I believe I burned GPIO23 and GPIO24. This is my hypothesis because twice I tried to touch the thermocouple to warm it up and felt a bit of a shock and immediately the sensor stopped reporting data and ssh disconnected. I also had some difficulty transferring the files from the raspberry pi to my computer.

Q5. How did you overcome the challenges or remedy the problems encountered?¶

To overcome these challenges, I wrapped the thermocouple in a bit of anti-static material that was delivered with my raspberry pi. I also changed the boot config file to look at GPIO 22 instead of 23. To overcome the challenge of transferring files, I decided to use sftp from my computer instead of using WinSCP since I am more familiar with the commands for the sftp protocol.
